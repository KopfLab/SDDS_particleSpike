Device data

Downloads copies of the data bursts queued on the device (data recorded while it was offline). The queue on the device is not changed - the data is still published to the cloud once the device is online. Downloaded bursts are stored in this browser, so Fetch data only transfers bursts it doesn't have yet.

Flash firmware

Pick the new firmware file (.bin) and click Flash. The device must be connected via USB and will be put into DFU mode: when prompted, you must select the device from the available serial devices, and then select it again once the device is in DFU mode.

Tree

Connect Bluetooth to a device advertising the Nordic UART Service (listed under its cloud device name), or Connect Serial to a device on USB running the SDDS serial spike (115200 baud). Expanding a struct subscribes to its values (L), collapsing unsubscribes (U).
